Adaptive Dating Recommendation System

A Java-based Capstone Project demonstrating Object-Oriented Programming, the DAO Design Pattern, and a simple profile recommendation algorithm.

Project Overview

User Management

Stores user information including age, city, gender, income and interests.

Interest Matching

Suggests compatible profiles using user attributes and preferences.

DAO Pattern

Separates data access logic from application logic using interfaces and implementations.

Java OOP

Implements encapsulation, objects, constructors, getters and setters.

Java Classes Used

UserAccount

Stores user profile information.

Interest

Stores likes, dislikes and hobbies.

UserAccountDAO

Defines database operations.

UserAccountDAOImpl

Implements matching and data retrieval.

UserAccountController

Runs the application and manages users.

Matching Algorithm

Step 1

User enters Age, City and Gender.

Step 2

DAO searches all stored users.

Step 3

Profiles with matching Age, City and opposite Gender are selected.

Step 4

Recommended profiles are displayed.
